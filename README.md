# 카드 사진·주문표 브라우저 비교 버전

기존 Mac용과 분리한 GitHub Pages용 정적 사이트입니다.

## GitHub Pages
이 폴더의 **내용**을 전용 저장소 루트에 올립니다. Settings → Pages → Deploy from a branch → main / (root)를 선택합니다. 생성된 HTTPS 주소를 북마크하세요.
고객 파일, 기존 프로젝트 폴더 전체, 설정키는 업로드하지 마세요. 이 배포 폴더에는 고객 파일과 키가 없습니다.

## 사용
index.html에서 사진 편집 → cards.html에서 주문서 선택 → 표 확인·수정 → JSX 다운로드 → Illustrator 20장 템플릿에서 실행.
file:// 더블클릭은 ES module/worker 제약으로 지원하지 않습니다. GitHub Pages 또는 로컬 HTTP로 여세요.

## 지원 및 한계
- PDF: 텍스트로 된 행(번호·이름·인증일). 스캔 OCR 미지원.
- Excel/CSV: 認定番号·氏名·認定日 또는 대응하는 한글 열.
- PPTX: 해당 열이 있는 표 또는 한 줄에 번호·이름·날짜가 있는 텍스트. 이미지, 임의 배치·다양한 서식은 자동 판독하지 못할 수 있어 원문·추출 수 확인 필요.
- 최대 20명, 파일 25MB, PDF/PPTX 50장.
- 얼굴 인식은 Apple Vision 대신 MediaPipe 얼굴 상자 기반입니다. 머리·턱 여백을 확인하세요.
- 파일은 브라우저 메모리에서 처리하며 업로드 API가 없습니다. 새로고침하면 입력 내용은 사라집니다.
- 얼굴 인식의 WASM·모델은 jsDelivr/Google에서 내려받으므로 최초 사용에 인터넷이 필요합니다. 사진은 전송하지 않습니다.
- JSX 치환 로직은 기존 버전을 사용합니다. 이번 검증은 생성·다운로드까지이며 Illustrator 재실행 시험은 포함하지 않았습니다.

## 포함 라이브러리
JSZip 3.10.1 (MIT/GPLv3), SheetJS CE 0.18.5 (Apache-2.0), PDF.js 4.10.38 (Apache-2.0), MediaPipe Tasks Vision 0.10.22-rc.20250304 (Apache-2.0). 배포 시 원본 라이선스 고지를 유지합니다.

사진 편집 화면에 PPTX를 넣으면 슬라이드에 삽입된 JPG/PNG/WebP 원본 이미지를 추출합니다. 같은 이미지 파일은 한 번만 추출하며, 로고도 포함될 수 있습니다. 슬라이드에서 적용한 자르기/회전은 반영하지 않습니다. 자동 이름 연결은 하지 않습니다.

좌우 90도 회전 및 확대 ±0.05배 버튼·숫자 입력 지원. 회전 시 구도를 다시 분석하며 원본은 보존합니다.

확대 슬라이더 0.5~1.5배(1배 중앙), 배율 직접 입력/± 버튼 지원. 1배 미만 또는 회전 시 사진 밖 여백은 흰색입니다. PPTX는 영문 포함 번호와 인접 이름을 위치로 추정하며 반드시 연결을 확인하세요. 원문에 날짜가 없으면 빈칸입니다.

사진 편집에서 넣은 마지막 PPTX는 같은 탭의 주문표 화면으로 한 번 전달됩니다. 전달용 파일은 브라우저 저장소에 임시 저장되며 주문표에서 읽을 때 삭제됩니다. 주문표에서는 드래그 앤 드롭으로도 파일을 넣을 수 있습니다.

주문표 각 항목에 복사 버튼, 날짜 2칸과 YYYY.MM.DD 표기 지원. 두 번째 날짜는 복사용이며 JSX는 첫 날짜만 치환합니다. PPTX 사진 후보는 위치 기반 추정이므로 사용자 확인이 필요합니다.
